Intel MAC4 4004 macro cross-assembler, version 2.5 (MAC4.SAV); MAC40 4040
macro cross-assembler, version 2.5 (MAC40.SAV); its expanded version 2.4
(MAC40E.SAV); and the INTERP/4 and INTERP/40 simulators, version 1.1
(INT4.SAV, INT40.SAV).
Original software: Intel Corporation; PDP-10 Fortran/Tymshare runtime authors.
These historical third-party executables are not newly authored project code.
No new license or public-domain status is asserted for them, and they are not
distributed with this repository.

Directory: (UPL), files MAC4.SAV, MAC40.SAV, MAC40E.SAV, INT4.SAV and INT40.SAV.
Runtime banners: 4004 MACRO ASSEMBLER, VER 2.5; 4040 MACRO ASSEMBLER, VER 2.5;
4040 MACRO ASSEMBLER, VER 2.4 (MAC40E); INTERP/4  VERS 1.1; INTERP/40 VERS 1.1.
The same directory holds MAC4.INF and MAC40.INF (release notes for 2.3 to 2.5),
MAC4.EXA (a 1974 MAC4 session) and SIM4, the earlier simulator that INTERP/40
replaced in July 1975 (SIM4.DAT).

Recovered with intel/recover.py. Each original 36-bit word is represented
as an unsigned eight-byte little-endian integer. No original word values
were patched in these files. The host runner's separate, documented
in-memory compatibility change omits discontinued Tymshare accounting.
